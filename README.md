# StudyLoop

StudyLoop is an independent local study app built from the ground up. It contains no AcedIt source code, private account data, or AcedIt branding or artwork.

## Run locally

1. Install Node.js 20 or newer.
2. Open a terminal in this folder and run `node server.mjs` (or `npm.cmd start` in PowerShell).
3. Open <http://127.0.0.1:4173>.

There are no package dependencies. Study data is saved in this browser on this computer; there is no account or cloud sync in this edition. Use Settings to export or restore a JSON backup.

## Included workflows

- Empty-by-default dashboard, profile and subject hubs
- User-created flashcards, active recall and spaced repetition
- User-created quizzes, self-marked attempts and a mistake review queue
- Pomodoro timer, blurting sessions and editable mind maps
- Assessment dates, scheduled sessions, weekly intention and session target
- Progress summaries based on saved sessions and quiz results
- AI tool pages and an optional provider-key connection scaffold

StudyLoop does not ship sample learner records or claim official VCAA marks. Any course areas, assessment weights, study materials and results shown are entered by the user.
